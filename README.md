## 🏛️ Архитектурная триада поиска: SEO vs. GEO vs. AEO

Современный поисковый маркетинг трансформировался из одномерной борьбы за позиции в трехмерную оптимизацию:

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        СОВРЕМЕННЫЙ ПОИСКОВЫЙ ЛАНДШАФТ                  │
├─────────────────────┬──────────────────────────┬───────────────────────┤
│    1. Классический  │      2. Генеративный     │     3. Ответный       │
│       SEO           │         GEO              │        AEO            │
├─────────────────────┼──────────────────────────┼───────────────────────┤
│ Поисковики:         │ Модели:                  │ Форматы:              │
│ Google, Yandex      │ ChatGPT, Perplexity,     │ Featured Snippets,    │
│ (10 синих ссылок)   │ Яндекс Нейро, DeepSeek   │ PAA, Алиса, Siri      │
├─────────────────────┼──────────────────────────┼───────────────────────┤
│ Механика:           │ Механика:                │ Механика:             │
│ Краулинг страниц,   │ Векторный RAG, извле-    │ Извлечение атомарного │
│ PageRank, ссылочный │ чение сущностей, синтез  │ ответа (Direct Answer)│
│ вес, плотность клю- │ обобщающего ответа,      │ под конкретный вопрос │
│ чевых фраз.         │ оценка Information Gain. │ без перехода на сайт. │
└─────────────────────┴──────────────────────────┴───────────────────────┘
```

## 📊 Матрица сигналов поисковых систем нового поколения

### 2.1. Сигналы SEO (Традиционный веб)
* **Title & Meta Description:** Title длиной 45–65 символов с первичным интентом; Meta Description 120–160 символов с коммерческим УТП.
* **Иерархия заголовков:** Строго единичный H1 на странице; логическое каскадирование H2 и H3 без пропусков уровней.
* **Crawlability & Robots:** Корректный `robots.txt` без случайных блокировок краулеров, карта сайта `sitemap.xml` и канонические теги `canonical`.
* **Доступность контента:** Семантические теги `alt` у изображений, чистый семантический HTML без перегрузки клиентским JS.

### 2.2. Сигналы GEO (Синтез в LLM и RAG)
GEO оптимизирует контент для нейросетей, формирующих синтезированные ответы из нескольких источников. Нейросети отдают приоритет доказательности, авторитету и плотности фактов:

1. **E-E-A-T (Опыт, Экспертиза, Авторитетность, Надежность):**
   * **Явное указание авторов:** Страницы авторов с квалификацией, сертификатами и ссылками на внешние профили (`Person` schema).
   * **Страница «О компании» / «Команда»:** Подтверждение реального опыта, юридические реквизиты, публикации в независимых СМИ.
   * **Сигналы доверия:** Сертификаты, кейсы с цифрами, награды, независимые отзывы.
2. **Фактоидная плотность (Factual Density):**
   * Насыщенность текста проверяемыми цифрами, статистикой, датами и техническими спецификациями. Нейросети цитируют точные данные, а не размытый маркетинговый текст.
3. **Прямые утверждения (Clear Claims & Inverted Pyramid):**
   * Формулировка ключевого факта или ответа в первых двух предложениях страницы. Принцип перевернутой пирамиды позволяет LLM быстрее зацепиться за смысл при ограниченном контекстном окне.
4. **Information Gain (Оригинальность информации):**
   * Публикация первичных данных исследований, уникальных бенчмарков или авторских методик. Модели штрафуют компилятивный рерайт и поощряют первоисточники.
5. **Entity Clarity (Однозначность сущностей в графе знаний):**
   * Использование `Organization` schema со свойством `sameAs`, связывающим сайт с Wikipedia, Telegram, Habr, VC.ru, GitHub и профилями в агрегаторах.
6. **Трассируемость источников (Source Provenance):**
   * Прямые ссылки на авторитетные нормативные документы, ГОСТы, научные статьи и первоисточники.

### 2.3. Сигналы AEO (Прямые ответы и Voice Search)
AEO оптимизирует сайт для попадания в блоки быстрых ответов (Featured Snippets), поисковые подсказки (People Also Ask) и голосовые ассистенты:

1. **Формула «Direct Answer Paragraph»:**
   * Компактный абзац на **40–60 слов** строго под вопросительным заголовком H2/H3.
   * Первое предложение строится по модели определения: *«[Термин] — это [категория], которая [ключевое свойство]»*.
2. **Вопросительные заголовки (Question-phrased Headings):**
   * Использование естественного языка запросов: *«Как работает X?», «Сколько стоит Y в 2026 году?», «В чем разница между A и B?»*.
3. **Структуры списков и таблиц:**
   * Маркированные и нумерованные списки (`<ul>`, `<ol>`) для пошаговых процедур.
   * Сравнительные таблицы (`<table>`) для сопоставления цен, тарифов и характеристик.
4. **Специализированная микроразметка:**
   * `FAQPage` — валидная структура вопрос-ответ с ответами до 300 символов.
   * `HowTo` — пошаговые инструкции с хронометражем и инструментами.
   * `SpeakableSpecification` — явная разметка блоков текста, предназначенных для зачитывания голосовыми ассистентами.

## 🛠️ Практические шаблоны и стандарты внедрения

### 3.1. Стандарт llms.txt и llms-full.txt
Манифест `llms.txt` — это файл в корне сайта (`/llms.txt`), предоставляющий краулерам ИИ очищенную базу знаний компании в формате Markdown:

* **[Эталонный шаблон templates/llms.txt](templates/llms.txt):**
  ```markdown
  # Название Компании
  > Краткое машиночитаемое резюме о профиле деятельности и ключевых услугах компании.

  ## Ключевые разделы
  - [Услуги и Тарифы](https://example.com/pricing): Детальная сетка цен без скрытых платежей
  - [Кейсы и Результаты](https://example.com/cases): Подтвержденные результаты внедрения
  - [Документация и API](https://example.com/docs): Технические руководства
  ```

---

### 3.2. SSR и Nginx-маршрутизация для AI-ботов
Краулеры поисковых нейросетей (`GPTBot`, `PerplexityBot`, `YandexRender`, `ClaudeBot`) не исполняют тяжелый клиентский JavaScript (SPA, React, Vue).

* **[Конфигурация Nginx configs/nginx_ai_bots.conf](configs/nginx_ai_bots.conf):**
  Маршрутизирует запросы краулеров на пререндеренный HTML или отдает сжатый Markdown, обеспечивая ответ сервера быстрее 150 мс.

---

### 3.3. Семантические триплеты и RAG-чанкование
Для индексации в векторных базах данных (Qdrant, Pinecone, ChromaDB) контент должен разбиваться на семантические блоки, содержащие законченные триплеты:

$$\text{Субъект (Бренд)} \xrightarrow{\text{Предикат (Свойство)}} \text{Объект (Факт)}$$

* **[Скрипт RAG-чанкования scripts/rag_chunker.py](scripts/rag_chunker.py):** Автоматизирует нарезку текста на чанки по 250–500 токенов с сохранением связности контекста.

---

### 3.4. Микроразметка Schema.org для нейросетей
* **[Готовые шаблоны templates/schema_templates.json](templates/schema_templates.json):**
  * `Organization` со связанным графом сущностей `sameAs`.
  * `FAQPage` для атомарных ответов Zero-Click.
  * `HowTo` для пошаговых сценариев.
  * `SpeakableSpecification` для голосовых ассистентов.

## 🎯 Методология аудита сайта и приоритизация (Effort vs. Impact)

Для систематической работы над проектом рекомендации ранжируются по матрице усилий и отдачи:

| Приоритет | Тип проблемы | Примеры | Затраты (Effort) | Влияние (Impact) |
|---|---|---|:---:|:---:|
| 🔴 **Critical** | Блокирующие проблемы | Закрыт доступ в `robots.txt`, нет H1, сайт отдает пустой JS ботам | Низкие / Средние | ⚡ Критическое |
| 🟠 **High** | Фундаментальные сигналы | Отсутствует `Organization` & `FAQPage` schema, нет манифеста `llms.txt` | Средние | 🚀 Высокое |
| 🟡 **Medium** | Оптимизация структуры | Перевод H2 в вопросительную форму, добавление сравнительных таблиц | Средние | 📈 Среднее |
| 🟢 **Quick Win** | Быстрые победы | Добавление `sameAs` ссылок, корректировка длины Title/Meta | Минимальные | 🎯 Быстрый буст |
