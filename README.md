## 🧠 Что такое GEO и AEO?

* **GEO (Generative Engine Optimization)** — оптимизация цифрового присутствия бренда для упоминания и рекомендации в генеративных синтезах поисковых LLM.
* **AEO (Answer Engine Optimization)** — структурирование контента сайта в виде прямого, верифицированного и авторитетного ответа на вопрос пользователя (Zero-Click Answers).

---

## 📄 Стандарт llms.txt и llms-full.txt

Стандарт `llms.txt` — это файл манифеста в корне сайта (`/llms.txt`), очищенный от HTML-мусора, стилей и скриптов, содержащий краткое резюме сайта для краулеров ИИ.

* [Шаблон llms.txt от Dreaper Lab](templates/llms.txt) — эталонный файл для коммерческих и B2B компаний.
* `llms-full.txt` — полный дамп базы знаний компании для глубокого индексирования в векторных хранилищах.

## ⚡ SSR и Динамический Пререндеринг для AI-ботов

Большинство краулеров искусственного интеллекта (включая `GPTBot` и `PerplexityBot`) имеют жесткие лимиты на выполнение клиентского JavaScript (SPA, React, Vue).

* [Конфигурация Nginx для маршрутизации AI-ботов](configs/nginx_ai_bots.conf) — отдача чистого пререндеренного HTML/Markdown при обнаружении User-Agent нейросети.
* Снижение TTFB для ботов ниже 200 мс гарантирует попадание в контекстное окно моделей.

## 🧩 Семантические триплеты и подготовка под RAG

Нейросети извлекают информацию в виде графов знаний:  
`Субъект (Бренд) ──[Предикат (Свойство)]──► Объект (Значение)`

* [Скрипт чанкования и выделения триплетов](scripts/rag_chunker.py) — модуль нарезки текстов под векторные базы (Qdrant, Pinecone, ChromaDB).
* Исключение размытых формулировок и привязка каждого факта к независимому источнику.

## 🏷️ Микроразметка Schema.org для нейросетей

Для попадания в ответы Google AI Overviews и Яндекс Нейро критически важны типы:
* `schema.org/Product` с полями `offers`, `aggregateRating`, `positiveNotes`.
* `schema.org/FAQPage` с атомарными ответами до 300 символов.
* `schema.org/Organization` с явной связью сущностей (`sameAs` на Википедию, Habr, VC, TenChat).
